Cahier des Charges : Pipeline MuseScore vers Arrangeur MIDI

1. Objectif du Projet

Établir un pipeline automatisé « one-click » permettant de convertir des partitions MuseScore (.mscz) en une lecture MIDI linéaire fluide, pilotant un clavier arrangeur Yamaha en temps réel. Le système doit gérer nativement la structure musicale complexe (répétitions, boîtes/voltas, sauts Da Capo / Dal Segno, codas) tout en garantissant une simplicité maximale d'exécution.

2. Architecture Globale (Le Pipeline en 3 Étapes)

Le système repose sur une architecture découplée en trois modules indépendants :

Étape 1 : L'Extraction (ms2grid.py)

  • Rôle : Analyser le fichier source MuseScore (.mscz / .mscx).
  • Fonctionnalités :
    • Extraction des métadonnées du header (titre, compositeur, etc.).
    • Parcours mesure par mesure pour extraire les accords (Harmony), les chiffrages de mesure (timesig), les barres de reprise (BarLine), les voltas, ainsi que les repères textuels et sauts (Marker, Jump, system_texts).
    • Génération d'un fichier JSON structuré et riche (score.json).

Étape 2 : La Compilation / Aplatissement (Le Compilateur)

  • Rôle : Jouer le rôle de « GPS musical » hors-ligne.
  • Fonctionnalités :
    • Prendre en entrée le JSON riche issu de l'étape 1.
    • Résoudre toute la logique de navigation (dérouler les boucles de reprises, alterner boîte 1 et boîte 2, interpréter les sauts D.C. / D.S. vers les repères Segno et Coda).
    • Générer une liste plate et chronologique d'accords purs avec leurs durées temporelles, en faisant le choix d'abandonner l'interactivité en direct au profit d'une simplicité et d'une robustesse absolues.

Étape 3 : La Lecture MIDI (remotedArranger.py)

  • Rôle : Transmettre les flux MIDI au clavier arrangeur.
  • Fonctionnalités :
    • Consommer la liste plate d'accords du début à la fin de manière strictement séquentielle.
    • Gérer le minutage précis selon le tempo (BPM) de la grille.
    • Envoyer les notes d'accord (Note On / Note Off) via la bibliothèque rtmidi.
    • Assurer une terminaison propre : en cas d'arrêt (manuel via le bouton de l'interface ou signal SIGINT), envoi d'un message All Notes Off, des codes de réinitialisation MIDI, du message Transport Stop (0xFC) et du SysEx d'arrêt propriétaire Yamaha pour stopper net l'arrangeur sans notes orphelines.

3. Interface Graphique et Ergonomie (gridEditor.py)

  • Un bouton unique intelligent "Play/Stop" qui pilote et suit l'état du sous-processus de lecture en temps réel (root.after).
  • Suppression de tous les popups superflus pour fluidifier l'expérience utilisateur.
  • Enregistrement automatique du dernier fichier ouvert (lastFile.json) pour un accès rapide.

4. Résumé du Flux de Données (Workflow)

  1. Saisie visuelle de la partition dans MuseScore (.mscz).
  2. Extraction par ms2grid.py → JSON riche.
  3. Compilation par le module dédié → Liste plate d'accords séquentiels.
  4. Lecture par remotedArranger.py → Sortie MIDI vers le clavier arrangeur.
